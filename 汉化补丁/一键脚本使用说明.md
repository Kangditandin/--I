# RimWorld 汉化 · 一键脚本使用说明

本方案**体积极小**（仅需下载 1.9 MB 补丁），代价是需要在 Termux 里跑一条命令。

---

## 一、文件清单

| 文件 | 大小 | 说明 |
|---|---|---|
| `一键汉化.sh` | ~4.7 KB | 一键脚本 |
| `汉化补丁_仅新增文件.zip` | 1.86 MB | 1120 个中文文件（补丁本体） |
| `RimWorld_0.1.0.apk` | 662 MB | 原版底包（你自己已有） |

> 三个文件放**同一个目录**（默认放 `/storage/emulated/0/MT2/mcp`）。

---

## 二、准备 Termux

1. 安装 **Termux**（应用商店或 F-Droid）。
2. 授予存储权限，执行一次：
   ```bash
   termux-setup-storage
   ```
3. 无需额外安装包（只用系统自带 `python3`；若提示缺 python，执行 `pkg install python -y`）。

---

## 三、一键运行

```bash
cd /storage/emulated/0/MT2/mcp
bash 一键汉化.sh
```

脚本会自动：
1. 从 `RimWorld_0.1.0.apk` 里提取原版 `RimWorldCore.zip`
2. 合入 1120 个中文文件
3. 校验（条目应为 19025）
4. 产出 **`RimWorldCore.zip`**（约 469,644,022 字节）

也可指定路径：
```bash
bash 一键汉化.sh /path/to/RimWorld_0.1.0.apk /path/to/汉化补丁_仅新增文件.zip
```

---

## 四、把产物放进 APK（MT 管理器）

1. 用 **MT 管理器** 打开 `RimWorld_0.1.0.apk` → 选 **APK 编辑**
2. 进入 `assets/`
3. **删除**原有的 `RimWorldCore.zip`
4. 把刚生成的 `RimWorldCore.zip`（在 `/storage/emulated/0/MT2/mcp/`）**添加**进 `assets/`
   - ⚠️ 文件名必须正好是 `RimWorldCore.zip`
   - ⚠️ 别再压缩一层（不要出现 `RimWorldCore.zip.zip`）
5. 返回上一级 → **签名** → 得到新 APK

---

## 五、安装

- 装的是**原版**：签名不同 → 需**先卸载原版再装**（存档在应用私有目录，卸载会丢档，请先备份）
- 装过**同证书汉化版**（`a40da80a…`）：可**直接覆盖安装**

---

## 六、常见问题

**Q：跑脚本报 `找不到 python3`？**
```bash
pkg install python -y
```

**Q：产出条目不是 19025？**
说明补丁或 APK 不对。确认用的是原版 `RimWorld_0.1.0.apk`（662,699,851 B）+ 本补丁。

**Q：脚本能重复跑吗？**
可以，幂等。多次运行结果一致（已实测）。

**Q：合入后 APK 会比原来大吗？**
会，内层增加约 1.9 MB。

**Q：不想用 Termux 怎么办？**
改用「独立整包」方案：直接下载 `RimWorldCore_汉化版.zip`（468 MB），MT 里替换 `assets/RimWorldCore.zip` 即可，无需脚本。

---

## 七、原理说明（为什么必须重建 zip）

- 汉化内容只**新增**文件（1120 个），**不改不删**任何原文件。
- 但 APK 内的 `RimWorldCore.zip` 是 **STORED（未压缩）** 存放，直接追加字节会破坏 APK 的 zip 偏移结构。
- 因此必须：**解出内层 → 重打包 → 塞回 APK → 重签名**。脚本负责前三步中最重的"重建 zip"，MT 负责最后的替换与签名。
