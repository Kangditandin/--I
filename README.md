# RimWorld AI 汉化版（手机版）

RimWorld 手机版的中文汉化，**本体 + 5 个 DLC** 全中文。

**怎么用？超简单：**

1. 去 **Releases** 页面，下载 **APK 安装包**。
2. 直接安装。
   - 装过原版的，先卸载原版再装（记得先备好存档）。
3. 进游戏 → 设置 → 语言 → **简体中文**。

完事。
