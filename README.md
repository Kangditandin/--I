# RimWorld AI 汉化版（手机版）

> 给 **RimWorld 手机版**（`RimWorld_0.1.0.apk`，原版底包 662 MB）用的完整中文汉化。
> 覆盖 **本体 + 5 个 DLC**：Core、Royalty、Ideology、Biotech、Anomaly、Odyssey。
> 中文内容只**新增文件、不改不删**原版任何文件，安全可回退。

---

## 一、我该下载哪个文件？（先看这个）

Release 里通常有两个东西，**大小差很多，用途不同**：

| 下载文件 | 大小 | 是什么 | 适合谁 |
|---|---|---|---|
| 🔵 **大的那个**（`RimWorldCore_汉化包.zip`，约 468 MB） | 大 | **已经导入汉化的完整资源包**，替换进 APK 就能用 | **推荐所有人**，一步到位 |
| 🟢 **小的那个**（`汉化补丁_仅新增文件.zip`，约 1.9 MB） | 小 | 只是 1120 个中文文件的**补丁**，需配合脚本自己合入 | 想省流量、会用 Termux 的人 |

> 一句话：
> - **怕麻烦 → 下大的**（468 MB 整包，直接替换，不用跑脚本）
> - **省流量 / 想自己折腾 → 下小的**（1.9 MB 补丁 + 跑一条命令）

两个的**最终效果完全一样**，随便挑一个都行。

## 二、方案 A：用大包（推荐，最简单）

**你需要：** `RimWorldCore_汉化包.zip`（468 MB）+ 原版 `RimWorld_0.1.0.apk` + **MT 管理器**。

1. 打开 **MT 管理器**，找到 `RimWorld_0.1.0.apk`
2. **长按 → 打开方式 → APK 编辑**
3. 进入 `assets/` 文件夹，里面有个 `RimWorldCore.zip`
4. **删除**它
5. 把下载的 `RimWorldCore_汉化包.zip` 添加进 `assets/`
6. **重命名为 `RimWorldCore.zip`** ⚠️ 名字必须一字不差
   - 别出现 `RimWorldCore.zip.zip`（不要二次压缩）
7. 返回上一级 → **签名**（用 MT 默认测试签名即可）
8. 安装生成的 APK

✅ 完成。进游戏 → 设置 → 语言 → 简体中文。

---

## 三、方案 B：用小补丁（省流量，需要 Termux）

**你需要：** `汉化补丁_仅新增文件.zip`（1.9 MB）+ `一键汉化.sh` + 原版 APK + Termux + MT 管理器。

### 1. 准备 Termux
```bash
termux-setup-storage
# 若提示缺 python：pkg install python -y
```

### 2. 把三个文件放同一目录（默认 `/storage/emulated/0/MT2/mcp`）
- `RimWorld_0.1.0.apk`
- `汉化补丁_仅新增文件.zip`
- `一键汉化.sh`

### 3. 跑脚本
```bash
cd /storage/emulated/0/MT2/mcp
bash 一键汉化.sh
```
脚本会自动从 APK 里提取原版资源包 → 合入 1120 个中文文件 → 校验 → 产出 `RimWorldCore.zip`（约 469 MB）。

### 4. 把产物放进 APK
和方案 A 的第 3~8 步一样：MT 管理器进 `assets/` → 删原 `RimWorldCore.zip` → 加入刚生成的 `RimWorldCore.zip` → **签名** → 安装。

## 四、安装注意（重要）

- 如果你手机上装的是**原版**：签名不同，**必须先卸载原版再装**。
  ⚠️ 卸载会清掉存档（存档在应用私有目录），**装之前先备份存档**。
- 如果你之前装的就是**汉化版**（同证书 `a40da80a…`）：可以**直接覆盖安装**，存档不丢。

## 五、怎么确认汉化成功？

进游戏 → **设置 → 语言 → 简体中文**，检查：
- 建造菜单、心情/社交面板是中文
- 加载界面提示是中文
- DLC 的情景名、剧情是中文

还是英文？多半是**替换的路径/文件名不对**，或忘了把文件名改回 `RimWorldCore.zip`。

## 六、常见问题

**Q：能直接把 zip 丢手机存储当 MOD 用吗？**
不能。这游戏的资源包在 APK 内部，不读外部目录。

**Q：替换后游戏闪退/打不开？**
通常是打包出错。检查：
- 新包用 zip 能正常打开（内层条目应为 **19025** 个）
- 没有二次压缩（不要 `RimWorldCore.zip.zip`）
- 整包 md5 应为 `3665dd1cfe13c2ae4223f8ea5f2d6a37`

**Q：跑脚本报找不到 python3？**
```bash
pkg install python -y
```

**Q：脚本能重复跑吗？**
可以，幂等，结果一致。

**Q：合入后 APK 会变大吗？**
会大一点（内层多约 1.9 MB）。

## 八、原理（为什么必须重建 zip）

汉化只**新增**文件、不动原文件。但 APK 里的 `RimWorldCore.zip` 是 **STORED（未压缩）** 存放，直接追加字节会破坏 APK 的 zip 结构。所以必须：**解出内层 → 重打包 → 塞回 APK → 重签名**。
