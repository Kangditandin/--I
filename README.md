# RimWorld AI 汉化版（手机版）

> 给 **RimWorld 手机版**（`RimWorld_0.1.0.apk`，原版底包 662 MB）用的完整中文汉化。
> 覆盖 **本体 + 5 个 DLC**：Core、Royalty、Ideology、Biotech、Anomaly、Odyssey。
> 中文内容只**新增文件、不改不删**原版任何文件，安全可回退。

---

## 一、推荐：直接下安装包

**最简单的方式**——去本仓库的 **Releases** 页面，下载**已经汉化好的安装包**，装到手机上直接用，不需要任何额外操作。

**安装前注意：**
- ⚠️ **先备份存档**（存档在应用私有目录，卸载会丢）。
- 如果手机上是**原版**或**别的汉化版**（签名不同），需要**先卸载再装**，不能直接覆盖。
- 如果之前装的就是**同证书汉化版**（`a40da80a…`），则可直接覆盖安装。

装好后进游戏 → **设置 → 语言 → 简体中文** 即可。

## 二、进阶：用补丁自己合入（省流量）

如果你想省流量，或者想自己在原版 APK 上操作，用这个方式。

**需要准备：**

| 文件 | 说明 |
|---|---|
| 原版 `RimWorld_0.1.0.apk` | 662 MB 底包，你自己已有 |
| `汉化补丁_仅新增文件.zip` | 约 1.9 MB，1120 个中文文件（在 Releases 里） |
| `一键汉化.sh` | 本仓库提供 |
| Termux + MT 管理器 | 手机上装 |

### 步骤

**1. 准备 Termux**
```bash
termux-setup-storage
# 若提示缺 python：pkg install python -y
```

**2. 把三个文件放同一目录**（默认 `/storage/emulated/0/MT2/mcp`），跑脚本：
```bash
cd /storage/emulated/0/MT2/mcp
bash 一键汉化.sh
```
脚本会自动从原版 APK 里提取资源包 → 合入 1120 个中文文件 → 校验 → 产出 `RimWorldCore.zip`（约 469 MB）。

**3. 用 MT 管理器替换进 APK**
- 长按 APK → **打开方式 → APK 编辑**
- 进入 `assets/`，**删除**原有的 `RimWorldCore.zip`
- 把刚生成的 `RimWorldCore.zip` 加进去（⚠️ 名字必须一字不差，别二次压缩成 `.zip.zip`）
- 返回 → **签名** → 安装

---

## 三、怎么确认汉化成功？

进游戏 → **设置 → 语言 → 简体中文**，检查建造菜单、心情/社交面板、DLC 情景名是否都是中文。
还是英文？多半是替换路径或文件名不对，或忘了把文件名改回 `RimWorldCore.zip`。

## 四、常见问题

**Q：能直接把补丁 zip 丢手机存储当 MOD 用吗？**
不能。这游戏的资源包在 APK 内部，不读外部目录。

**Q：替换后游戏闪退？**
通常是打包出错。检查新包能正常打开（内层条目应为 **19025** 个），且没有二次压缩。

**Q：脚本能重复跑吗？**
可以，幂等，结果一致。
